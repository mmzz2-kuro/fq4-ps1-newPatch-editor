# 퍼스트퀸 4 PS1 세이브 에디터

`FQ4-PS1-Save-Editor.exe`를 실행하고 DuckStation의 raw `.mcd` 파일을 엽니다. FQ4 슬롯과 캐릭터 레코드를 선택해 값을 바꾼 뒤 **선택 캐릭터에 적용**을 누르고 **다른 이름으로 저장**합니다.

캐릭터 이름과 전체 CLASS 목록을 표시하며 CLASS, FT, LV, HP, HR, AT, AR, DF, DR을 편집할 수 있습니다. 이름은 게임의 640개 이름표와 세이브의 이름 ID를 연결해 표시합니다. 원본 파일은 기본적으로 덮어쓰지 않으며, 출력 파일을 다시 읽어 카드 구조와 FQ4 내부 체크섬을 검증합니다.

CLASS 변경은 캐릭터 외형과 동작에도 영향을 줍니다. 종족 제한 확장 옵션을 적용하지 않은 게임에서는 여러 CLASS를 한 부대에 넣을 때 원래 그래픽 예산 제한이 적용됩니다.

프리셋은 HR·HP·AT·AR·DF·DR을 기본으로 저장하며 CLASS·LV·FT를 선택적으로 포함합니다. 캐릭터 목록에서 Ctrl 또는 Shift로 여러 명을 고른 뒤 한 번에 적용할 수 있습니다. 프리셋은 `%APPDATA%\FQ4SaveEditor\presets.json`에 저장됩니다.

CLASS 선택 창의 그림은 원본 디스크의 `/CHR*/Cxx.P`에서 앞모습 타일 `16=좌상`, `17=좌하`, `18=우상`, `19=우하`를 조합한 실제 32×32 자세입니다. 색상은 CLASS 25 인게임 화면과 대조해 승인된 검정·은색·빨강·노랑 정규화 팔레트를 사용합니다.
