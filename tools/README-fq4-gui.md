# 퍼스트퀸4 일반 BIOS용 한글 ROM 생성 GUI

## 권장 실행

Python 설치 없이 다음 파일을 실행한다.

```text
tools/dist/FQ4-Standard-BIOS-Korean-Tool.exe
```

## Python 소스 실행

Python 3가 설치된 Windows에서는 다음 파일을 실행한다.

```text
python tools/fq4_bios_independent_gui.py
```

## 필요한 파일

- 일본판 원본 `First Queen IV - Varcia Senki (Japan).bin`
- 호환 구조를 유지한 퍼스트퀸4 한글패치 `.xdelta` (`241112`, `250826` 검증 완료)
- 한글 글꼴이 들어 있는 `SCPH1001.BIN`
- `xdelta.exe`

GUI에 네 입력 파일과 출력 BIN 경로를 지정하고 **일반 BIOS용 ROM 만들기**를 누른다. 성공하면 출력 BIN과 같은 이름의 CUE가 생성된다. 에뮬레이터와 ODE에서는 생성된 CUE를 연다.

## 선택 기능

### 엔딩 후 결산 화면 수정 적용

기본값은 켜짐이다. 이 옵션은 엔딩 동영상 이후 검은 화면과 결산 화면 라벨 깨짐을 피하기 위한 수정이다.

적용 내용:

- `/MOV/MOV04.STR;1`을 원본 동영상 섹터로 대체한다.
- 엔딩 후 캐릭터 결산 화면의 고정 템플릿을 원본 구조로 되돌리고 라벨만 게임 코드 기준 한글로 넣는다.
- 적용 라벨: `이름`, `직업`, `파워`, `격추`, `전장에서생환!`, `에서사망`

### 부대 종족 제한 확장

기본값은 꺼짐이다. 선택하면 종족별 그래픽 비용 합계의 허용 범위를 일반 비용 종족 18종 수준까지 확장한다. 실제 허용 수는 종족별 비용에 따라 달라질 수 있다.

## 검증

도구는 xdelta 적용 결과에서 실행 파일과 ISO 구조를 검사한 뒤 전체 디스크의 Mode 2 Form 1 EDC와 P/Q ECC를 자동으로 다시 계산한다. 완료된 BIN은 전체 43,002개 sector 검사에서 sync, header, subheader, EDC, P, Q 오류가 없어야 성공으로 확정된다.

일본판 원본과 한글 BIOS는 SHA-256으로 검사한다. xdelta의 파일명·날짜·SHA-256은 제한하지 않으며 적용 결과가 `fq4-korean-sjis-v1` 구조 프로필을 통과해야 한다. 실행 파일 훅, 빈 코드 영역, DUMMY.DUM 공간 또는 raw sector 구조가 호환되지 않으면 출력 없이 중단한다.

입력 파일은 수정하지 않는다. 작업 중에는 출력 폴더의 숨김 임시 BIN 한 개를 사용하며, 성공하면 결과 BIN으로 바꾸고 실패하거나 취소하면 제거한다. 기존 출력이 있으면 GUI가 덮어쓰기 여부를 먼저 묻는다.
