# FQ4 캐릭터 팔레트 편집기

원본 PS1 BIN에서 클래스 스프라이트를 읽고 클래스별 팔레트 인덱스 색상을 편집해 64×64 PNG로 출력하는 도구입니다.

1. `원본 BIN`에서 일본판 원본 BIN을 선택하고 `열기`를 누릅니다.
2. 클래스를 선택한 뒤 팔레트 인덱스를 선택합니다.
3. HEX 또는 RGB 값을 입력하고 `사용자 색상 적용`을 누릅니다.
4. `저장`으로 `class_palettes.json`에 기록합니다.
5. 선택 클래스나 전체 클래스 PNG를 출력합니다.

사용자 색상이 없는 인덱스는 기존 세이브 에디터 이미지 추출기의 색상을 사용합니다. 인덱스 0은 투명색으로 고정됩니다. 이 도구는 원본 BIN과 기존 세이브 에디터 이미지를 수정하지 않습니다.

캐릭터 이미지 아래의 `팔레트 레이어 인덱스` 화면은 같은 인덱스를 같은 구분색으로 표시합니다. 픽셀에 마우스를 올리면 출력 좌표, 인덱스 번호, 현재 색상과 색상 출처가 표시됩니다. 픽셀을 클릭하면 오른쪽 목록의 같은 인덱스가 선택되고 해당 인덱스 영역이 흰색으로 강조됩니다. 구분색은 확인용이며 JSON이나 출력 PNG에는 반영되지 않습니다.

`다른 클래스에 적용`을 누르면 현재 클래스의 사용자 색상을 한 개 이상의 다른 클래스에 복사할 수 있습니다. 대상이 실제로 사용하는 같은 인덱스만 적용됩니다. `병합`은 대상의 다른 설정을 유지하고, `교체`는 대상 설정을 지운 뒤 공통 인덱스만 적용합니다. 결과는 먼저 메모리에 반영되며 `마지막 복사 취소`로 되돌리거나 상단 `저장`으로 JSON에 기록할 수 있습니다.
