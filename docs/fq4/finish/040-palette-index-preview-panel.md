# FQ4 FINISH-040 팔레트 레이어 인덱스 확인 패널

## 완료 내용

팔레트 편집기의 실제 캐릭터 이미지 아래에 별도의 `팔레트 레이어 인덱스` 미리보기를 추가했다. 실제 색상과 인덱스 구분색을 동시에 확인할 수 있으며, 인덱스 화면의 픽셀과 오른쪽 팔레트 목록을 양방향으로 연결했다.

## 화면 동작

- 상단에는 사용자 팔레트가 반영된 캐릭터 이미지를 표시한다.
- 하단에는 같은 64×64 좌표의 팔레트 인덱스 구분 이미지를 표시한다.
- 같은 인덱스의 픽셀은 같은 확인용 구분색을 사용한다.
- 마우스를 올리면 다음 정보를 표시한다.
  - 출력 좌표
  - 팔레트 인덱스
  - 현재 HEX 색상
  - 사용자/기존/고정 출처
- 픽셀을 클릭하면 오른쪽 목록의 같은 인덱스를 선택한다.
- 오른쪽 목록에서 인덱스를 선택하면 해당 인덱스 영역을 흰색으로 강조하고 나머지 영역을 어둡게 표시한다.
- 확인용 구분색과 강조색은 팔레트 JSON 및 출력 PNG에 반영하지 않는다.

## 렌더러 변경

`tools/scripts/fq4_class_sprite.py`에 실제 출력 이미지와 정확히 대응하는 64×64 인덱스 맵 생성을 추가했다.

- 2×2 이미지는 기존 방식대로 최근접 확대한다.
- 3×3 이상 이미지는 실제 이미지와 같은 투명 영역 자르기, 최근접 축소, 중앙 정렬을 적용한다.
- 따라서 class 174, 211~218 같은 대형 이미지도 화면 좌표와 팔레트 인덱스가 일치한다.
