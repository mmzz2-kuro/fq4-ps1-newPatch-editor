# FQ4-FINISH-019 세이브 에디터 프리셋 정보 표시

- 완료일: 2026-09-14
- 상태: **완료**
- 실행 파일: `tools/dist/FQ4-PS1-Save-Editor.exe`

## 완료 내용

- 캐릭터 편집 하단의 프리셋 영역에 읽기 전용 상세 정보 표시부를 추가했다.
- 선택한 프리셋의 `HR`, `HP`, `AT`, `AR`, `DF`, `DR` 값을 한눈에 확인할 수 있게 했다.
- 선택 항목인 `CLASS`, `LV`, `FT`를 함께 표시한다.
- CLASS는 숫자 ID와 클래스 이름을 함께 표시한다.
- 프리셋에 저장되지 않은 선택 항목은 `미포함 (현재 값 유지)`로 표시한다.
- 프리셋 선택 변경, 새 프리셋 저장 및 삭제 직후 표시 내용이 자동 갱신된다.
- 프리셋이 없을 때는 선택 가능한 프리셋이 없다는 안내를 표시한다.
