# FQ4-FINISH-003 — 일반 BIOS 대표 화면 시각 런타임 검증 결과

- 날짜: 2026-09-13
- 계획: [FQ4-PLAN-003](../plans/003-normal-bios-visual-runtime.md)
- 사용자 승인: 2026-09-13 “진행해봐”
- 기술 판정: **실패 확인 — 선택 메뉴 문자열은 현재 PoC에서도 한글 BIOS에 의존**

## 1. 실행 결과

보존된 일반 BIOS와 현재 PoC ROM의 해시를 확인하고 DuckStation을 새로 실행했다. 로그에서 다음 항목을 확인했다.

- 게임 ID: `SLPS-00604`
- 선택 BIOS: `SCPH-1001 ... (v2.2 12-04-95 A)`
- BIOS 지역: NTSC-U
- 디스크 지역: NTSC-J
- 시스템 부팅과 커널 초기화 완료

일본판 디스크와 NTSC-U BIOS의 지역 불일치 경고가 있었지만 부팅 자체는 완료됐다.

이후 사용자가 같은 지도 메뉴를 BIOS만 바꾸어 두 번 촬영했다. 일반 BIOS 캡처에서는 메뉴 글리프가 한자·기호 형태로 잘못 표시되고, 동봉 한글 BIOS 캡처에서는 `시간경과`, `부대이동`, `탐색`을 포함한 한글 메뉴가 정상 표시된다. 두 화면은 모두 1200×914이며 지도와 메뉴 배치가 같아 BIOS별 글리프 결과를 직접 비교할 수 있다.

## 2. 시각 판정

화면 자동화 서비스 초기화가 `Trusted RPC service is not configured`로 실패했다. 대체 API도 제공되지 않았으며 세션을 초기화해 다시 연결했을 때 Windows 샌드박스 ACL 적용 실패로 자동화 커널이 종료됐다.

자동화 실행 중에는 대표 화면을 보지 못한 상태에서 키 입력을 추정하지 않았다. 이후 사용자 캡처로 다음 결과를 확인했다.

- 일반 BIOS: 메뉴 문자 다수가 대응하지 않는 일본어 한자·기호 글리프로 표시됨
- 동봉 한글 BIOS: `시간경과`, `부대이동`, `탐색`을 정상 판독 가능
- 지도, 메뉴 창과 캐릭터 그래픽은 두 캡처에서 유지됨
- 종료 후 재진입과 글리프 수명은 아직 확인하지 않음

현재 PoC에는 “교섭중”의 세 글리프만 들어 있으므로 새 대표 문자열의 실패는 구현 범위와 일치한다. 이번 결과는 지도 메뉴가 한글 BIOS 글리프에 실제로 의존한다는 기준 화면을 확정한다. 선행 PLAN-002의 세 글리프가 이 메뉴 전체를 처리한다고 주장하지 않는다.

## 4. 다음 권장 작업

다음 계획에서는 대표 대상을 `시간경과`, `부대이동`, `탐색`으로 고정하고 다음 순서로 진행하는 것이 적절하다.

1. 세 문자열의 실제 패치 코드열과 중복을 제거한 글리프 집합을 찾는다.
2. 필요한 글리프를 현재 최소 ROM 조회 PoC에 넣을 수 있는지 용량과 배치를 검토한다.
3. 가능하면 같은 작업 ROM 한 벌에 메뉴 전용 PoC를 만들고 일반 BIOS 화면을 다시 촬영한다.
4. 같은 메뉴의 한글 BIOS 캡처와 글자 형태, 배치와 주변 UI를 비교한다.

이 구현과 ROM 변경은 별도의 계획 문서와 사용자 확인 후 수행한다.
