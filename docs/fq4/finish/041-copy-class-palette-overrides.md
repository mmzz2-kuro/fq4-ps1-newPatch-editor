# FQ4 FINISH-041 사용자 팔레트 다른 캐릭터에 적용

## 완료 내용

현재 클래스에 입력한 사용자 팔레트 색상을 다른 클래스 한 개 이상에 복사하는 기능을 팔레트 편집기에 추가했다. 대상 클래스가 실제로 사용하는 동일한 팔레트 인덱스만 적용한다.

## 사용 방법

1. 원본 클래스에서 사용자 색상을 입력한다.
2. `다른 클래스에 적용` 버튼을 누른다.
3. 번호나 이름으로 검색하고 대상 클래스를 한 개 이상 선택한다.
4. 모든 사용자 색상 또는 현재 선택 인덱스만 적용할지 선택한다.
5. `병합` 또는 `교체`를 선택하고 적용한다.
6. 결과를 확인한 뒤 상단 `저장` 버튼으로 JSON에 기록한다.

## 적용 방식

- 병합
  - 원본과 대상이 함께 사용하는 인덱스를 복사한다.
  - 대상 클래스에만 있던 기존 사용자 색상은 유지한다.
- 교체
  - 대상 클래스의 기존 사용자 색상을 제거한다.
  - 원본과 대상이 함께 사용하는 인덱스만 새로 기록한다.
- 인덱스 0과 대상이 사용하지 않는 인덱스는 복사하지 않는다.
- 적용 전 대상 클래스 수, 적용 색상 수, 건너뛸 색상 수를 표시한다.
- 적용 결과는 먼저 메모리에만 반영된다.
- `마지막 복사 취소`로 직전 다중 클래스 복사를 한 번 되돌릴 수 있다.
