# FQ4-FINISH-021 현재 파일 저장 및 CLASS 이미지 미리보기

- 완료일: 2026-09-14
- 상태: **완료**
- 실행 파일: `tools/dist/FQ4-PS1-Save-Editor.exe`

## 완료 내용

### 현재 파일 저장

- 상단에 `현재 파일 저장` 버튼을 추가했다.
- 버튼을 누르면 `정말로 덮어 씌우시겠습니까?` 확인 메시지를 표시한다.
- 확인한 경우에만 현재 불러온 `.mcd` 또는 `.srm` 경로에 저장한다.
- 취소하거나 불러온 파일이 없으면 파일을 변경하지 않는다.
- 저장에는 기존 임시 파일 작성, 검증, 원자적 교체 절차를 사용한다.
- 저장 직후 현재 파일을 다시 열어 PS1 디렉터리와 FQ4 내부 체크섬을 재검증한다.
- 기존 `다른 이름으로 저장` 기능을 유지했다.

### 현재 CLASS 이미지

- 캐릭터 편집 패널의 CLASS 항목 바로 아래에 32×32 이미지와 CLASS ID·이름을 표시한다.
- 캐릭터 목록에서 선택한 캐릭터의 현재 CLASS 이미지가 즉시 표시된다.
- CLASS 콤보박스를 변경하면 적용 전 미리보기가 즉시 바뀐다.
- 이미지 목록에서 CLASS를 선택해도 편집 패널의 미리보기가 즉시 갱신된다.
- PLAN-018에서 승인된 150개 CLASS 이미지를 그대로 사용한다.
