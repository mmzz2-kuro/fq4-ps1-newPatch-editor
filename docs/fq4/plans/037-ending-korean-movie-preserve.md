# FQ4 PLAN-037: 한글 자막 엔딩 동영상 유지 및 결산 화면 전환 수정

작성일: 2026-09-15

## 목표

PLAN-034에서 엔딩 동영상 이후 내 캐릭터 정산/결과 화면으로 넘어가지 않고 검은 화면이 되는 문제를 수정했습니다. 다만 현재 수정 방식은 `MOV04`를 일본어 원본 디스크의 파일로 교체하기 때문에, 한글패치본에 들어 있던 한글 자막 엔딩 동영상이 일본어 원본 동영상으로 되돌아갑니다.

이번 작업의 목표는 한글패치된 엔딩 동영상, 특히 한글 자막이 들어간 `MOV04`를 유지하면서도 동영상 재생 후 결산 화면으로 정상 전환되도록 만드는 것입니다.

## 현재 상태

- 원본 일본어판
  - 최종 보스 클리어
  - 씬 전환 대사
  - 엔딩 동영상 재생
  - 내 캐릭터 결산/결과 화면 표시
  - 타이틀 복귀

- 기존 한글패치판
  - 최종 보스 클리어
  - 씬 전환 대사
  - 한글 자막 엔딩 동영상 재생
  - 내 캐릭터 결산/결과 화면에서 검은 화면

- PLAN-034 수정본
  - 결산 화면 전환은 복구됨
  - 하지만 `MOV04`가 일본어 원본으로 교체되어 한글 자막 동영상이 사라짐

## 가설

`MOV04` 전체가 문제라기보다, 한글패치판 `MOV04`의 일부 메타데이터/스트림 종료부/섹터 ECC-EDC/STR 프레임 경계/후속 전환 타이밍 중 하나가 원본과 달라 결산 화면 진입 시 문제가 생겼을 가능성이 큽니다.

따라서 `MOV04` 전체를 원본으로 되돌리는 대신, 한글 자막 영상 데이터는 유지하고 문제를 유발하는 최소 범위만 원본 또는 정상 구조로 복구하는 방향을 우선 조사합니다.

## 원본 보존 원칙

- `original/`, `patched/`, `korean-patch/`의 원본 디스크 이미지는 수정하지 않습니다.
- 작업 산출물은 `work/fq4/037/` 또는 `out/`에 생성합니다.
- 분석 스크립트는 `tools/scripts/`에 작성합니다.
- ROM 빌더 GUI/엔진 변경이 필요하면 기존 파일을 갱신하되, 원본 ROM은 직접 수정하지 않습니다.
- 대용량 ROM 복사본은 불필요하게 계속 만들지 않고, 검증용 산출물을 제한적으로 생성합니다.

## 조사 계획

1. `MOV04` 위치와 크기 재확인
   - PLAN-034에서 사용한 LBA 범위와 크기를 재확인합니다.
   - 원본, 241112 한글패치, 250826 한글패치, 현재 빌더 산출물의 `MOV04`를 비교합니다.

2. 한글패치판 `MOV04`의 구조 점검
   - raw sector 수, mode/form, ECC/EDC 상태 확인
   - STR/MDEC 프레임 헤더 후보 확인
   - 원본과 첫/마지막 섹터 및 종료부 차이 비교

3. 최소 수정 후보 생성
   - 후보 A: 한글패치판 `MOV04` 유지 + ECC/EDC만 정상 재계산
   - 후보 B: 한글패치판 `MOV04` 유지 + 마지막 N개 섹터만 원본 종료부로 교체
   - 후보 C: 한글패치판 `MOV04` 유지 + STR 종료/패딩/후속 sector metadata만 원본 구조로 보정
   - 후보 D: `MOV04`는 한글패치판 유지, 결산 화면 전환 코드/파일 로드 쪽만 보정

4. 테스트용 이미지 생성
   - 기존 빌더 흐름에 후보 옵션을 추가하기 전, `tools/scripts/`의 분석/테스트 스크립트로 후보 ROM을 생성합니다.
   - 각 후보는 `work/fq4/037/`에 제한적으로 생성합니다.

5. 사용자 런타임 확인
   - 최종 보스 이후 엔딩 동영상 자막이 한글로 나오는지 확인합니다.
   - 동영상 종료 후 결산 화면이 정상 진입하는지 확인합니다.
   - 결산 화면의 한글 텍스트 수정이 유지되는지 확인합니다.

6. 빌더 반영
   - 성공 후보가 확인되면 `tools/scripts/build_fq4_bios_independent.py`의 엔딩 수정 옵션을 개선합니다.
   - GUI 체크박스 문구도 “엔딩 후 결산 화면 수정”이 한글 자막 동영상을 유지한다는 의미로 갱신합니다.
   - 필요 시 기존 원본 `MOV04` 통째 교체 방식은 fallback 옵션 또는 내부 예외로만 남깁니다.

7. 완료 문서 작성
   - `docs/fq4/finish/037-ending-korean-movie-preserve.md`
   - 성공한 후보, 실패한 후보, 남은 리스크, 빌더/GUI 변경점, 검증 결과를 기록합니다.

## 확인 포인트

- 엔딩 동영상 자막이 한글패치판 그대로 나오는지
- 동영상 종료 후 결산 화면이 정상 표시되는지
