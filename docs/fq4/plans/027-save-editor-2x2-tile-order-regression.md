# FQ4-PLAN-027 기존 2x2 CLASS 타일 순서 복구
- 작성일: 2026-09-14
- 상태: **완료**
- 대상 도구: `tools/FQ4SaveEditor/`
- 관련 스크립트: `tools/scripts/extract_fq4_class_icons.py`
- 완료 문서 예정: `docs/fq4/finish/027-save-editor-2x2-tile-order-regression.md`

## 1. 문제

PLAN-026에서 2x2 아이콘의 크기 규격은 복구했지만, 타일 순서가 잘못 유지됐다.

사용자 확인에 따르면 2x2 앞모습 타일 `16~19`는 다음 순서다.

```text
16 = 좌상
17 = 좌하
18 = 우상
19 = 우하
```

따라서 화면 배치는 다음과 같아야 한다.

```text
16 18
17 19
```

현재 추출기는 일반 행 우선 순서로 읽어 `16 17 / 18 19` 형태가 되어 CLASS 25 같은 기존 정상 이미지가 틀어졌다.

## 2. 목표

- 2x2 리소스의 타일 순서를 `좌상, 좌하, 우상, 우하` 기준으로 복구한다.
- 3x3 대형 리소스의 세로열 우선 배치는 유지한다.
- 기존 2x2 크기 규격인 64x64 단순 확대도 유지한다.

## 3. 구현 방향

- `extract_fq4_class_icons.py`의 타일 offset 계산을 2x2와 3x3 모두 세로열 우선으로 처리한다.
- 일반 2x2는 `base_tile=16`, `width_tiles=2`, `height_tiles=2`, `column_major=true`로 기록한다.
- compact 2x2도 같은 순서가 맞는지 확인하되, 리소스가 4타일뿐이라 같은 세로열 우선 조합을 적용한다.
- 3x3은 PLAN-025에서 확인한 `0 3 6 / 1 4 7 / 2 5 8` 배치를 유지한다.

## 4. 검증

- CLASS 25가 `16 18 / 17 19` 조합으로 정상 표시되는지 확인한다.
- CLASS 174와 183 이후 대형 3x3 항목이 유지되는지 확인한다.
- `class_catalog.json` 220개 항목을 유지한다.
- 세이브 에디터 EXE를 다시 빌드한다.

## 5. 원본 보존

`original/`, `patched/`, `korean-patch/`, `memcard/`, `savestates/`, `dos-save/`는 읽기만 하며 수정하지 않는다.

## 6. 완료 조건

- 2x2 타일 순서 회귀가 복구된다.
- 3x3 대형 보정이 유지된다.
- 확인용 이미지와 완료 문서가 작성된다.
