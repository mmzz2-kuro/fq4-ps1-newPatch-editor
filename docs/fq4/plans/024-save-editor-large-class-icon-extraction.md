# FQ4-PLAN-024 세이브 에디터 대형 CLASS 이미지 추출 보정
- 작성일: 2026-09-14
- 상태: **완료**
- 대상 도구: `tools/FQ4SaveEditor/`
- 관련 스크립트: `tools/scripts/extract_fq4_class_icons.py`
- 완료 문서 예정: `docs/fq4/finish/024-save-editor-large-class-icon-extraction.md`

## 1. 문제

세이브 에디터의 CLASS 이미지 목록에서 174, 183 이후 일부 항목이 잘리거나 깨져 보인다. 현재 아이콘 추출기는 모든 `Cxx.P` 리소스를 16×16 타일 4개로 구성된 32×32 앞모습으로 가정한다.

사용자 관찰상 해당 항목들은 일반 캐릭터보다 큰 스프라이트로 보이며, 이 때문에 기존 고정 조합 방식이 실제 프레임 구조와 맞지 않을 가능성이 높다.

## 2. 목표

- CLASS 174와 183 이후 깨지는 항목들의 실제 타일/프레임 구조를 조사한다.
- 일반 32×32 캐릭터와 대형 스프라이트를 구분하는 규칙을 만든다.
- 세이브 에디터의 CLASS 이미지가 잘리지 않도록 아이콘 추출 방식을 보정한다.
- 기존 CLASS 25 등 정상 항목의 이미지 품질은 유지한다.

## 3. 분석 방향

1. `original-files.json`의 `/CHR*/Cxx.P` 크기와 현재 `class_catalog.json`의 이미지 상태를 비교한다.
2. 174, 183, 184, 185, 186, 187, 188 등 문제 구간의 파일 크기와 타일 수를 확인한다.
3. 각 리소스에서 16×16 타일을 격자로 펼친 미리보기 이미지를 생성해 실제 프레임 배열을 찾는다.
4. 큰 리소스가 32×48, 48×48, 64×64 등 어떤 조합을 쓰는지 분류한다.
5. 아이콘 표시 영역에 맞게 투명 여백을 기준으로 자동 crop/fit하는 방식을 검토한다.

## 4. 구현 방향

- `tools/scripts/extract_fq4_class_icons.py`에 리소스별 프레임 후보 추출 로직을 추가한다.
- 일반 캐릭터는 기존처럼 앞모습 타일 `16,17,18,19` 기준을 유지한다.
- 대형 스프라이트는 조사 결과에 따라 별도 tile rectangle 또는 자동 crop 방식을 적용한다.
- 출력 PNG는 기존 `tools/FQ4SaveEditor/class_icons/class-NNN.png` 파일명을 유지해 GUI 코드를 크게 바꾸지 않는다.
- `class_catalog.json`에는 각 항목의 추출 방식, 원본 타일 범위, 이미지 크기/상태를 기록한다.

## 5. 사용자 확인 지점

먼저 문제 구간의 후보 미리보기 이미지를 `docs/fq4/analysis/024/`에 생성한다. 사용자가 확인하기 쉽게 174, 183 이후 항목 중심으로 몇 가지 후보를 한 장에 모아 비교한다.

후보 중 실제 인게임에 가까운 조합이 확인되면 그 규칙을 전체 아이콘 추출에 반영한다.

## 6. 검증

- 174, 183 이후 문제 항목이 더 이상 잘리지 않는지 미리보기 이미지로 확인한다.
- CLASS 25 같은 기존 정상 항목이 유지되는지 확인한다.
- `class_catalog.json` 항목 수가 220개로 유지되는지 확인한다.
- 세이브 에디터 GUI에서 CLASS 선택 목록과 현재 CLASS 미리보기가 정상 표시되는지 확인한다.
- 필요하면 EXE를 다시 빌드한다.

## 7. 원본 보존

`original/`, `patched/`, `korean-patch/`, `memcard/`, `savestates/`, `dos-save/`는 읽기만 하며 수정하지 않는다. ROM 전체 복사본은 만들지 않고, 작은 분석 이미지와 JSON만 생성한다.

## 8. 완료 조건

- 문제 구간 대형 스프라이트의 원인이 문서화된다.
- 사용자 확인을 거친 추출 규칙이 `extract_fq4_class_icons.py`에 반영된다.
- CLASS 아이콘 PNG와 catalog가 재생성된다.
- 완료 문서가 `docs/fq4/finish/024-save-editor-large-class-icon-extraction.md`에 작성된다.
