# FQ4 PLAN-040 팔레트 레이어 인덱스 확인 패널

## 상태

- 구현 및 검증 완료
- 결과는 `docs/fq4/finish/040-palette-index-preview-panel.md`에 기록했다.

## 배경

현재 팔레트 편집기는 캐릭터 이미지 미리보기와 `팔레트 인덱스 구분색 보기` 전환 기능을 제공한다. 하지만 실제 이미지와 인덱스 구분 화면을 동시에 비교할 수 없어 어느 색상 영역이 어떤 팔레트 인덱스인지 확인하기 불편하다.

## 목표

1. 기존 캐릭터 이미지 미리보기 하단에 팔레트 인덱스 전용 미리보기를 항상 표시한다.
2. 실제 색상 이미지와 인덱스 구분 이미지를 동시에 비교할 수 있게 한다.
3. 인덱스 이미지에서 픽셀을 가리키거나 선택하면 해당 팔레트 인덱스를 확인할 수 있게 한다.
4. 기존 이미지 크기·타일 배치·팔레트 편집 및 출력 동작은 유지한다.

## 구현 내용

### 화면 배치

- 중앙 미리보기 영역을 다음 순서로 구성한다.
  1. `캐릭터 이미지` 제목과 기존 색상 미리보기
  2. `팔레트 레이어 인덱스` 제목과 인덱스 구분 미리보기
  3. 선택한 픽셀 정보
- 두 미리보기 모두 원본 64×64 이미지를 최근접 보간으로 확대한다.
- 창 높이가 부족한 경우 중앙 영역을 스크롤할 수 있게 하거나 미리보기 확대 배율을 조정해 모든 편집 기능에 접근할 수 있게 한다.

### 인덱스 구분 이미지

- 투명 인덱스 0은 체크무늬 또는 투명 배경으로 구분한다.
- 나머지 인덱스는 서로 구분하기 쉬운 임시 색상으로 표시한다.
- 이 구분색은 확인용이며 사용자 팔레트 JSON과 출력 PNG에는 저장하거나 적용하지 않는다.
- 같은 팔레트 인덱스를 사용하는 모든 픽셀은 같은 구분색으로 표시한다.

### 픽셀과 인덱스 연동

- 인덱스 미리보기에서 마우스가 가리키는 위치의 다음 정보를 표시한다.
  - 출력 이미지 좌표
  - 팔레트 인덱스 번호
  - 현재 적용 RGB/HEX
  - 색상 출처: 사용자, 기존 또는 투명
- 인덱스 미리보기의 픽셀을 클릭하면 오른쪽 팔레트 인덱스 목록에서 같은 인덱스를 자동 선택한다.
- 오른쪽 목록에서 인덱스를 선택하면 인덱스 미리보기에서 해당 영역을 식별할 수 있도록 테두리 또는 별도 강조색을 표시한다.

### 기존 전환 기능 정리

- 현재 `팔레트 인덱스 구분색 보기` 체크박스는 제거한다.
- 상단 미리보기는 항상 실제 적용 색상으로 표시한다.
- 하단 미리보기는 항상 팔레트 인덱스 구분색으로 표시한다.
- 사용자 색상을 편집하면 상단 실제 색상 미리보기와 하단 정보 표시를 즉시 갱신한다.

## 검증 항목

1. 실제 색상 미리보기와 인덱스 미리보기가 동시에 표시되는지 확인한다.
2. class 25의 출력 픽셀을 클릭했을 때 올바른 원본 팔레트 인덱스를 선택하는지 확인한다.
3. 3×3·4×4·6×6·8×8 클래스에서도 축소·중앙 정렬 후 좌표와 인덱스가 올바르게 대응하는지 확인한다.
4. 목록에서 선택한 인덱스의 모든 픽셀이 미리보기에서 강조되는지 확인한다.
5. 사용자 RGB 변경 후 실제 미리보기와 픽셀 정보가 즉시 갱신되는지 확인한다.
6. 인덱스 구분색이 저장 JSON과 출력 PNG에 섞이지 않는지 확인한다.
7. 기존 220개 PNG 출력 결과와 배치가 변경되지 않았는지 재검증한다.
8. GUI 실행 파일을 다시 빌드하고 시작 검사를 수행한다.

## 원본 보호

- 원본 ROM과 한글패치 자료를 수정하지 않는다.
- 기존 세이브 에디터 이미지와 세이브 데이터를 수정하지 않는다.
- 전체 ROM 복사본을 추가로 만들지 않는다.
