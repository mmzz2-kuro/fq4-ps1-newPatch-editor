# FQ4 PLAN-039 캐릭터 팔레트 편집 및 이미지 출력 GUI

## 상태

- 사용자 확인 대기
- 이 문서는 계획만 정의하며, 확인 전에는 구현하지 않는다.

## 배경

현재 세이브 에디터의 클래스 이미지는 `tools/scripts/extract_fq4_class_icons.py`가 ROM의 클래스 스프라이트를 읽어 64×64 PNG로 출력한다. 클래스별 타일 크기와 배치는 이미 확인되어 있으며 2×2, 3×3, 4×4, 6×6, 8×8 예외도 반영되어 있다.

색상은 공통 변환표를 기본으로 사용하고 클래스 000과 010만 코드 내부의 별도 색상표를 사용한다. 앞으로 사용자가 클래스별 실제 색상을 직접 조사해 입력할 수 있도록 이미지 출력 부분을 독립 GUI 도구로 분리할 필요가 있다.

## 목표

1. 기존 세이브 에디터의 스프라이트 해석·배치 로직을 복사해 독립 도구로 만든다.
2. 선택한 클래스가 사용하는 팔레트 인덱스별 RGB 값을 GUI에서 입력하고 즉시 미리 볼 수 있게 한다.
3. 입력한 색상만 덮어쓰고, 입력하지 않은 인덱스는 현재 추출기의 기존 색상을 그대로 사용한다.
4. 선택 클래스 또는 전체 클래스를 기존 세이브 에디터와 같은 크기와 배치의 PNG로 출력한다.
5. 원본 ROM과 기존 세이브 에디터 이미지는 자동으로 수정하지 않는다.

## 구현 범위

### 1. 독립 스프라이트 렌더링 모듈

- 위치: `tools/scripts/`
- 기존 추출기에서 다음 동작을 독립 모듈로 복사하거나 분리한다.
  - 클래스 리소스 탐색 및 해석
  - 타일 인덱스와 픽셀 인덱스 복원
  - 기존 클래스별 배치 규칙
  - 64×64 출력과 대형 이미지 축소·중앙 정렬
  - 기존 공통 팔레트와 클래스 000·010의 현재 예외 색상
- 기존 세이브 에디터 및 기존 추출기는 이번 단계에서 변경하지 않는다.

### 2. 사용자용 GUI

- 위치: `tools/FQ4PaletteEditor/`
- 주요 화면과 기능:
  - 클래스 번호와 이름 목록
  - 선택 클래스의 현재 64×64 이미지와 확대 미리보기
  - 해당 이미지에 실제로 사용된 팔레트 인덱스 목록
  - 인덱스별 색상 견본, HEX 값, R/G/B 입력란
  - 색상 선택 대화상자
  - 선택 인덱스 사용자 색상 사용/해제
  - 선택 클래스 저장, 변경 취소, 사용자 색상 초기화
  - 선택 클래스 PNG 출력, 전체 클래스 PNG 출력
  - 필요하면 팔레트 인덱스를 확인할 수 있는 인덱스 표시 미리보기
- 팔레트 인덱스 0은 투명색으로 유지한다.

여기서 팔레트 레이어는 클래스 이미지의 각 픽셀이 참조하는 **팔레트 인덱스** 단위로 처리한다. 같은 인덱스를 쓰는 픽셀은 같은 사용자 RGB 값을 적용받는다.

### 3. 팔레트 설정 파일

- 클래스별·인덱스별 사용자 색상은 ROM이나 Python 코드에 직접 기록하지 않고 별도 JSON 파일로 저장한다.
- 입력하지 않은 클래스 또는 인덱스는 JSON에 기록하지 않는다.
- 적용 우선순위:
  1. 사용자가 JSON에 입력한 클래스별 인덱스 색상
  2. 클래스 000·010의 기존 예외 색상
  3. 기존 공통 팔레트 색상
- 잘못된 RGB/HEX 값은 저장하지 않고 GUI에서 안내한다.
- 저장 중 파일이 손상되지 않도록 임시 파일을 거친 원자적 저장을 사용한다.

## 이미지 규격

- 최종 PNG: RGBA, 64×64
- 확대 미리보기는 최근접 보간을 사용한다.
- 현재 확정된 배치 규칙을 그대로 유지한다.
  - 일반 2×2: class 25를 포함한 기존 순서 유지
  - 대형 3×3: class 174 계열 규칙 유지
  - 4×4 base 64: class 211~216
  - 6×6 base 0: class 217
  - 8×8 base 0: class 218
- 사용자 색상이 하나도 없을 때에는 현재 추출 결과와 픽셀 단위로 같아야 한다.

## 출력 및 원본 보호

- 기본 출력 위치: `work/fq4/039/output/`
- GUI에서 사용자가 별도 출력 폴더를 선택할 수 있게 한다.
- `original/`, `patched/`, `korean-patch/`와 기존 `tools/FQ4SaveEditor/class_icons/`는 덮어쓰지 않는다.
- ROM은 읽기 전용 입력으로만 사용하며 전체 ROM 복사본을 새로 만들지 않는다.
- 나중에 색상 검수가 끝나면 별도 계획에서 확정 JSON을 세이브 에디터 이미지 생성 과정에 연결한다.

## 실행 파일

- GUI가 정상 동작한 뒤 PyInstaller 사양과 빌드 스크립트를 추가한다.
- 예정 위치:
  - `tools/packaging/fq4_palette_editor.spec`
  - `tools/scripts/build_fq4_palette_editor_exe.ps1`
  - `tools/dist/FQ4-Class-Palette-Editor.exe`

## 검증 항목

1. 빈 사용자 팔레트로 220개를 출력했을 때 기존 렌더러 결과와 모두 일치하는지 비교한다.
2. 한 클래스의 한 인덱스만 바꿨을 때 그 인덱스의 픽셀만 변경되는지 확인한다.
3. 사용자 색상을 해제하면 기존 색상으로 정확히 복원되는지 확인한다.
4. JSON 저장 후 다시 열었을 때 모든 사용자 색상이 동일하게 복원되는지 확인한다.
5. 잘못된 RGB/HEX 입력을 거부하는지 확인한다.
6. class 25, 174, 211, 212, 217, 218의 크기와 타일 배치를 별도로 확인한다.
7. 출력 PNG가 모두 RGBA 64×64인지 확인한다.
8. 원본 ROM, 기존 세이브 에디터 및 기존 클래스 이미지에 변경이 없는지 확인한다.
