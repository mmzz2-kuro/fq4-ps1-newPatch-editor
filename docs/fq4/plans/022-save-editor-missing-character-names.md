# FQ4-PLAN-022 세이브 에디터 누락 캐릭터 및 이름표 재검증

- 작성일: 2026-09-14
- 상태: **완료**
- 기준 사례: `트리스렌` (`TRISLEN` 계열 표기 가능성 포함)
- 사용자용 도구: `tools/FQ4SaveEditor/`
- 최종 실행 파일: `tools/dist/FQ4-PS1-Save-Editor.exe`
- 완료 문서 예정: `docs/fq4/finish/022-save-editor-missing-character-names.md`

## 1. 문제

게임 내 부대 목록에는 `트리스렌`이 존재하지만 현재 세이브 에디터에서는 찾을 수 없으며, 같은 방식으로 누락되거나 잘못 표시되는 캐릭터가 더 있을 가능성이 있다.

현재 에디터는 640개 후보 레코드 중 `HP > 0`, `CLASS < 150`, `name_id < 640` 조건을 통과한 레코드만 표시하고, 별도로 만든 `character_names.json`에서 `name_id`를 이름으로 변환한다. 따라서 레코드 필터, 이름 ID 해석, 이름표 추출 중 어느 한 곳의 문제가 누락을 만들 수 있다.

## 2. 분석 범위

### 세이브 레코드

- 제공된 `.mcd`와 RetroArch `.srm`의 모든 FQ4 슬롯에서 640개 레코드를 필터 없이 조사한다.
- 현재 표시 조건별로 제외된 레코드 수와 실제 값을 기록한다.
- 게임 화면의 `트리스렌` 능력치와 일치하거나 유사한 레코드를 찾아 record index, name ID, CLASS ID를 확정한다.
- 같은 name ID가 여러 record에 사용되는지, 캐릭터가 빈 레코드로 잘못 판정되는지 확인한다.

### 이름표

- 현재 `character_names.json`의 생성 근거와 640개 항목을 다시 검증한다.
- PS1 ROM의 실제 캐릭터 이름 데이터와 name ID 참조 관계를 재분석한다.
- DOS판 세이브·에디터 자료는 보조 대조표로만 사용하고 PS1 데이터와 일치 여부를 확인한다.
- 일본어·영어·한글 표기가 혼재한 항목은 원본 ID를 유지하면서 확인 가능한 이름을 병기한다.
- `트리스렌` 외에도 빈 이름, 클래스명으로 대체된 이름, 중복·오프셋 오류로 의심되는 항목을 전체 탐지한다.

## 3. 개선 방향

분석 결과에 따라 다음을 적용한다.

- 유효 캐릭터를 제외하는 필터 조건을 실제 세이브 구조에 맞게 수정한다.
- 잘못된 name ID 매핑과 누락 이름을 교정한다.
- 이름이 확정되지 않은 항목도 레코드를 숨기지 않고 `미확인 이름 (ID n)` 형태로 표시한다.
- 목록 검색 또는 정렬이 필요하면 이름과 record index를 기준으로 캐릭터를 쉽게 찾을 수 있게 보완한다.
- 이름 표시만 고치며 세이브의 name ID 자체는 사용자가 별도로 편집하지 않는 한 변경하지 않는다.

## 4. 검증

- 게임 화면의 `트리스렌`이 에디터에 표시되고 능력치와 CLASS가 같은지 확인한다.
- 제공된 모든 FQ4 슬롯에서 수정 전후 표시 레코드 수와 누락 항목을 비교한다.
- 기존에 화면 대조가 끝난 12개 캐릭터의 이름과 능력치가 유지되는지 검사한다.
- 전체 name ID가 범위를 벗어나도 GUI가 중단되지 않는지 확인한다.
- 무변경 저장은 입력과 바이트 단위로 같고, 편집 저장은 지정 필드와 체크섬만 바뀌는지 확인한다.
- `.mcd`와 `.srm` 회귀 테스트, Python 구문 검사, EXE 기동 검사를 수행한다.

## 5. 산출물

- 필요한 경우 수정된 `tools/scripts/fq4_memcard.py`와 GUI

## 6. 원본 보존

`original/`, `patched/`, `korean-patch/`, `memcard/`, `savestates/`, `dos-save/`는 읽기만 하며 수정하지 않는다. 분석용 결과는 작은 JSON/CSV만 저장하고, ROM이나 메모리카드 전체 복사본을 추가로 만들지 않는다.

## 7. 완료 조건

- `트리스렌`의 실제 record index와 name ID가 확인된다.
- 에디터에서 `트리스렌`을 포함한 유효 캐릭터가 누락 없이 표시된다.
- 잘못되거나 불완전한 이름표가 전체 재검증된다.
- 기존 편집·프리셋·CLASS 이미지·체크섬 기능에 회귀가 없다.
