# FQ4-PLAN-025 대형 CLASS 타일 순서 보정
- 작성일: 2026-09-14
- 상태: **완료**
- 대상 도구: `tools/FQ4SaveEditor/`
- 관련 스크립트: `tools/scripts/extract_fq4_class_icons.py`
- 완료 문서 예정: `docs/fq4/finish/025-save-editor-large-class-tile-order.md`

## 1. 문제

PLAN-024에서 대형 CLASS 리소스를 3x3타일 48x48 프레임으로 분류했지만, CLASS 174의 실제 타일 순서가 일반적인 행 우선 순서가 아니었다.

사용자 확인에 따르면 CLASS 174의 타일 0~8은 다음 순서다.

`좌상, 좌중, 좌하, 중상, 중간, 중하, 우상, 우중, 우하`

즉 파일 순서는 세로열 우선이며, 현재 추출기의 `좌상, 중상, 우상, 좌중, 중간, 우중, 좌하, 중하, 우하` 행 우선 조합과 다르다.

## 2. 목표

- CLASS 174의 3x3 프레임을 사용자 확인 순서에 맞게 재조합한다.
- 183 이후 108타일 대형 리소스도 같은 세로열 우선 순서인지 후보 이미지로 확인한다.
- 맞는 규칙이면 대형 리소스 전체에 적용한다.
- 199~202 72타일 드래곤 계열에도 같은 순서가 적용 가능한지 별도 확인한다.

## 3. 구현 방향

- `extract_fq4_class_icons.py`의 3x3 렌더링에 대형 리소스용 tile order를 추가한다.
- 대형 3x3 프레임의 좌표 매핑은 다음과 같이 적용한다.

| 화면 위치 | 파일 내 상대 타일 |
|---|---:|
| 좌상 | 0 |
| 좌중 | 1 |
| 좌하 | 2 |
| 중상 | 3 |
| 중간 | 4 |
| 중하 | 5 |
| 우상 | 6 |
| 우중 | 7 |
| 우하 | 8 |

- 일반 2x2 리소스는 기존 순서를 유지한다.
- 재생성 후 `docs/fq4/analysis/025/`에 174, 183~204 비교 이미지를 만든다.

## 4. 검증

- CLASS 174가 온전한 형태로 표시되는지 확인한다.
- CLASS 183~198 대형 인간형/장비형 항목의 깨짐이 줄어드는지 확인한다.
- CLASS 199~202 드래곤 계열이 개선되는지 확인하고, 여전히 별도 배치표가 필요한지 기록한다.
- `class_catalog.json` 220개 항목을 유지한다.
- 세이브 에디터 EXE를 다시 빌드한다.

## 5. 원본 보존

`original/`, `patched/`, `korean-patch/`, `memcard/`, `savestates/`, `dos-save/`는 읽기만 하며 수정하지 않는다. ROM 전체 복사본은 만들지 않는다.
