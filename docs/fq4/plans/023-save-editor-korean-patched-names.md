# FQ4-PLAN-023 세이브 에디터 한글패치 이름표 반영
- 작성일: 2026-09-14
- 상태: **완료**
- 대상 도구: `tools/FQ4SaveEditor/`
- 관련 스크립트: `tools/scripts/generate_fq4_editor_names.py`
- 완료 문서 예정: `docs/fq4/finish/023-save-editor-korean-patched-names.md`

## 1. 문제

현재 세이브 에디터의 캐릭터 이름이 일본어 기준으로 표시된다. 이전 022 작업에서 누락 캐릭터를 해결하기 위해 원본 PS-X EXE의 이름 테이블을 안정적인 기준으로 다시 추출했기 때문이다.

사용자가 원하는 방향은 한글패치가 적용된 게임 화면과 동일하게, 세이브 에디터에서도 캐릭터 이름을 한글패치 ROM의 이름 정보로 표시하는 것이다.

## 2. 목표

- 한글패치된 ROM 또는 xdelta 적용 결과에서 캐릭터 이름 테이블을 추출한다.
- 세이브 에디터의 `character_names.json`을 한글 표시명 중심으로 재생성한다.
- 한글패치 쪽에서 읽을 수 없는 항목은 원본 이름을 대조용 fallback으로 보존한다.
- `트리스렌`처럼 사용자가 화면에서 확인한 캐릭터가 한글명으로 표시되는지 검증한다.
- 기존 세이브 편집, 클래스 이미지, 프리셋, 현재 파일 저장 기능은 유지한다.

## 3. 분석 방향

1. 현재 이름 생성 스크립트가 참조하는 원본 EXE 이름 테이블 위치를 확인한다.
2. 한글패치 적용 ROM에서 같은 위치의 이름 테이블이 실제로 한글 코드 또는 패치 전용 코드로 바뀌어 있는지 확인한다.
3. 패치 ROM의 이름 바이트가 표준 CP949/UTF-8이 아니라 패치 전용 2바이트 코드일 가능성을 전제로, 기존 한글 폰트/문자 코드 분석 자료와 연결해 디코더를 만든다.
4. 이름 ID 0..639 전체를 추출하고, 원본 이름과 한글패치 이름을 나란히 기록해 깨진 항목과 빈 항목을 검증한다.
5. 검증된 한글명 목록을 `tools/FQ4SaveEditor/character_names.json`에 반영한다.

## 4. 구현 방향

- `tools/scripts/generate_fq4_editor_names.py`를 수정해 원본 ROM만이 아니라 한글패치 ROM도 입력 소스로 사용할 수 있게 한다.
- 패치 전용 문자 코드 디코딩이 필요하면 별도 helper를 스크립트 안에 추가하거나, 기존 분석 스크립트의 문자 매핑을 재사용한다.
- 결과 JSON은 GUI가 그대로 읽을 수 있는 기존 형식을 유지한다.
- 한글명이 없는 항목은 `한글명 / 원문명`처럼 무리하게 합치지 않고, 실제 표시 안정성을 우선해 fallback 규칙을 명확히 둔다.
- 필요하면 분석 결과를 `docs/fq4/analysis/023/`에 JSON/CSV로 남긴다.

## 5. 검증

- `트리스렌`의 name_id가 한글명으로 표시되는지 확인한다.
- 사용자가 제공한 2번째 세이브 슬롯의 주요 캐릭터들이 일본어가 아니라 한글명으로 보이는지 확인한다.
- `character_names.json` 항목 수가 640개로 유지되는지 확인한다.
- GUI에서 `.mcd`와 RetroArch `.srm`을 열 때 이름 표시와 저장 동작이 깨지지 않는지 테스트한다.
- Python 구문 검사와 세이브 에디터 EXE 빌드를 실행한다.

## 6. 원본 보존

`original/`, `patched/`, `korean-patch/`, `memcard/`, `savestates/`, `dos-save/`는 읽기만 하며 수정하지 않는다. ROM 전체 복사본은 새로 누적하지 않고, 필요한 경우 기존 작업용 파일 한 벌만 재사용한다. 생성물은 스크립트, 작은 분석 JSON/CSV, GUI 리소스, 최종 EXE로 제한한다.

## 7. 완료 조건

- 한글패치 ROM에서 캐릭터 이름 추출 가능 여부가 문서화된다.
- 가능한 범위의 한글 캐릭터 이름이 세이브 에디터에 반영된다.
- fallback된 이름은 이유와 개수가 기록된다.
- 기존 저장 편집 기능과 클래스 관련 UI가 정상 동작한다.
- 완료 문서가 `docs/fq4/finish/023-save-editor-korean-patched-names.md`에 작성된다.
