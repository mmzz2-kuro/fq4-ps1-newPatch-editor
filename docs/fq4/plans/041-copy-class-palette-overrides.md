# FQ4 PLAN-041 사용자 팔레트 다른 캐릭터에 적용

## 상태

- 구현 및 검증 완료
- 결과는 `docs/fq4/finish/041-copy-class-palette-overrides.md`에 기록했다.

## 배경

현재 팔레트 편집기는 클래스별로 팔레트 인덱스의 사용자 색상을 저장한다. 동일하거나 비슷한 색상 구성을 사용하는 캐릭터에도 같은 값을 적용하려면 각 인덱스를 다시 입력해야 하므로 반복 작업이 많다.

## 목표

1. 현재 클래스에 입력한 사용자 팔레트 값을 다른 클래스에 복사한다.
2. 한 클래스 또는 여러 클래스를 대상으로 선택할 수 있게 한다.
3. 대상 클래스가 실제로 사용하는 팔레트 인덱스에만 값을 적용한다.
4. 대상 클래스의 기존 사용자 색상을 유지하며 병합하거나 전체 교체하는 방식을 선택할 수 있게 한다.
5. 적용 결과를 저장 전에 미리 확인하고 취소할 수 있게 한다.

## 구현 내용

### 팔레트 복사 버튼

- 오른쪽 팔레트 편집 영역에 `다른 클래스에 적용` 버튼을 추가한다.
- 현재 클래스에 사용자 지정 색상이 하나도 없으면 버튼을 실행하지 않고 안내한다.

### 대상 클래스 선택 창

- 클래스 번호, 이름, 사용자 팔레트 설정 유무를 목록으로 표시한다.
- 검색어로 클래스 번호 또는 이름을 필터링한다.
- 단일 선택과 다중 선택을 지원한다.
- `전체 선택`, `선택 해제` 기능을 제공한다.
- 현재 클래스는 대상에서 제외한다.

### 적용 범위

- 기본값은 현재 클래스에 저장된 **모든 사용자 지정 인덱스**를 복사한다.
- 선택적으로 현재 오른쪽 목록에서 선택한 인덱스 하나만 복사할 수 있게 한다.
- 대상 클래스가 실제로 사용하지 않는 인덱스는 건너뛴다.
- 인덱스 0은 투명색이므로 복사하지 않는다.

### 병합과 교체

- `병합`을 기본값으로 한다.
  - 원본 클래스와 대상 클래스가 함께 사용하는 인덱스의 사용자 색상을 복사한다.
  - 대상 클래스에만 존재하는 기존 사용자 색상은 유지한다.
- `교체`를 선택하면 대상 클래스의 기존 사용자 색상을 먼저 제거한 뒤 원본과 대상이 함께 사용하는 인덱스만 기록한다.
- 실행 전에 대상 클래스 수, 복사될 인덱스 수, 건너뛸 인덱스 수를 요약해 표시한다.

### 저장과 취소

- 복사 결과는 우선 GUI 메모리에만 반영한다.
- 기존 상단 `저장` 버튼을 눌렀을 때 팔레트 JSON에 기록한다.
- 대상 클래스의 기존 값과 복사 후 값을 작업 단위로 기억하여 `마지막 복사 취소` 버튼으로 한 번 되돌릴 수 있게 한다.
- JSON 형식은 기존 `class_palettes.json` 구조를 유지한다.

### 결과 확인

- 복사가 끝나면 적용된 클래스 수, 적용된 색상 수, 사용하지 않아 건너뛴 인덱스 수를 표시한다.
- 대상 클래스로 이동하면 실제 미리보기와 인덱스 목록에서 복사된 색상을 즉시 확인할 수 있다.

## 검증 항목

1. 현재 클래스의 전체 사용자 팔레트를 단일 대상에 병합할 수 있는지 확인한다.
2. 여러 대상 클래스에 한 번에 적용할 수 있는지 확인한다.
3. 선택 인덱스 하나만 복사할 수 있는지 확인한다.
4. 대상이 사용하지 않는 인덱스가 JSON에 추가되지 않는지 확인한다.
5. 병합 시 대상 클래스의 다른 사용자 색상이 유지되는지 확인한다.
6. 교체 시 대상 클래스의 기존 사용자 색상이 제거되는지 확인한다.
7. `마지막 복사 취소`가 모든 대상 클래스를 이전 상태로 복원하는지 확인한다.
8. 저장 후 JSON을 다시 열었을 때 복사 결과가 동일한지 확인한다.
9. 기존 이미지 출력과 팔레트 인덱스 확인 기능이 변경되지 않았는지 재검증한다.
10. 실행 파일을 다시 빌드하고 시작 검사를 수행한다.

## 원본 보호

- 원본 ROM과 한글패치 자료를 수정하지 않는다.
- 기존 세이브 에디터 이미지와 세이브 데이터를 수정하지 않는다.
- 전체 ROM 복사본을 추가로 만들지 않는다.
