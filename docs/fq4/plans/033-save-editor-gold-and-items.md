# FQ4-PLAN-033 세이브 에디터 자금 및 보유 아이템 편집
- 작성일: 2026-09-14
- 상태: **사용자 확인 대기**
- 대상 도구: `tools/FQ4SaveEditor/`
- 관련 스크립트: `tools/scripts/fq4_memcard.py`
- 완료 문서 예정: `docs/fq4/finish/033-save-editor-gold-and-items.md`

## 1. 배경

PLAN-032의 CLASS 인덱스 지도 샘플 작업은 후반부 게임 화면 자료가 더 모일 때까지 보류한다.

다음 우선 작업은 세이브 에디터에 자금과 보유 아이템 편집 기능을 추가하는 것이다. 아이템은 이미 보유 중이면 수량을 수정하고, 보유하지 않은 아이템이면 새로 추가하는 형태가 필요하다.

## 2. 목표

- 세이브 데이터에서 자금(gold) 위치와 저장 형식을 확인한다.
- 세이브 데이터에서 보유 아이템 목록 구조를 확인한다.
- 세이브 에디터 GUI에 자금 수정 기능을 추가한다.
- 세이브 에디터 GUI에 아이템 수량 수정 및 미보유 아이템 추가 기능을 추가한다.
- 저장 시 기존 세이브 체크섬 계산을 유지한다.

## 3. 분석 범위

- 제공된 `.mcd`, RetroArch `.srm`, DuckStation savestate, DOS save/editor 자료를 읽기 전용으로 비교한다.
- 자금 값은 게임 화면 또는 기존 세이브 간 차이에서 위치 후보를 찾는다.
- 아이템 구조는 다음 정보를 우선 확인한다.

| 항목 | 확인 내용 |
|---|---|
| 아이템 ID | 아이템 종류를 구분하는 값 |
| 수량 | 최소/최대, 1바이트/2바이트 여부 |
| 빈 슬롯 | 미보유 아이템 추가 시 사용할 sentinel 값 |
| 정렬 | 게임 내 표시 순서와 세이브 저장 순서 |
| 용량 | 최대 보유 아이템 개수 |

## 4. 구현 방향

- 구조가 확인되면 `tools/scripts/fq4_memcard.py`에 gold/item 읽기·쓰기 API를 추가한다.
- GUI에는 캐릭터 편집과 분리된 자금/아이템 영역을 추가한다.
- 자금은 숫자 입력 + 적용 방식으로 처리한다.
- 아이템은 목록에서 현재 보유 아이템을 보여주고, 아이템 ID/이름/수량을 수정할 수 있게 한다.
- 미보유 아이템 추가는 빈 슬롯을 찾아 삽입한다.
- 아직 아이템 이름표가 완전히 확인되지 않으면 우선 `Item ID n` 형식으로 표시하고, 확인된 이름표는 별도 JSON으로 확장 가능하게 둔다.

## 5. 검증

- 자금 수정 후 세이브 체크섬이 정상 재계산되는지 확인한다.
- 기존 캐릭터 편집 기능이 유지되는지 확인한다.
- 아이템 수량 수정 후 다시 열었을 때 값이 유지되는지 확인한다.
- 미보유 아이템 추가 시 빈 슬롯에 들어가고 기존 아이템을 덮어쓰지 않는지 확인한다.
- `.mcd`와 `.srm` 모두 같은 방식으로 동작하는지 확인한다.
- EXE를 다시 빌드하고 실행 파일 해시를 기록한다.

## 6. 원본 보존

`original/`, `patched/`, `korean-patch/`, `memcard/`, `savestates/`, `dos-save/`는 읽기만 하며 수정하지 않는다. 테스트 저장은 `work/fq4/` 아래 작업용 메모리카드 파일 한 벌을 재사용한다.

## 7. 위험 및 미확정 항목

- 아이템 목록의 빈 슬롯과 최대 개수를 잘못 해석하면 기존 아이템을 덮어쓸 수 있다.
- 아이템 ID와 실제 이름 매핑은 별도 분석이 필요할 수 있다.
- 자금과 아이템이 세이브 슬롯 내부 체크섬 외 추가 검증값을 갖는지 확인해야 한다.

## 8. 완료 조건

- 자금 위치와 아이템 구조가 문서화된다.
- 세이브 에디터에서 자금과 아이템 수량을 편집할 수 있다.
- 미보유 아이템 추가가 가능하다.
- MCD/SRM 저장 검증이 통과한다.
- 완료 문서가 작성된다.
