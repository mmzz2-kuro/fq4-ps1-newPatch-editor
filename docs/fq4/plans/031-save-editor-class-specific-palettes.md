# FQ4-PLAN-031 세이브 에디터 CLASS별 팔레트 적용
- 작성일: 2026-09-14
- 상태: **완료**
- 대상 도구: `tools/FQ4SaveEditor/`
- 관련 스크립트: `tools/scripts/extract_fq4_class_icons.py`
- 완료 문서 예정: `docs/fq4/finish/031-save-editor-class-specific-palettes.md`

## 1. 문제

현재 세이브 에디터의 CLASS 아이콘은 공통 정규화 팔레트를 사용한다. 이 방식은 형태 확인에는 충분하지만, 캐릭터별 실제 인게임 색상과 맞지 않는 항목이 생긴다.

사용자가 CLASS 000 `왕 아레스(변신전)`과 CLASS 010 `엑소시스트(슈이키)`의 인게임 샘플 이미지를 제공했다. 이 두 항목부터 CLASS별 팔레트 보정을 시작한다.

## 2. 목표

- CLASS 000과 CLASS 010의 팔레트를 샘플 이미지에 가깝게 보정한다.
- 기존 타일 레이아웃 규칙은 유지한다.
- 보정 결과를 확인용 이미지로 먼저 출력한다.
- 확인 후 세이브 에디터 아이콘과 EXE에 반영한다.

## 3. 분석 방향

- 현재 추출 PNG의 색상 인덱스 분포와 샘플 이미지의 대표 색상을 비교한다.
- CLASS 000은 검정 머리, 피부색, 흰/하늘 갑옷, 초록 망토, 갈색 신발, 검 흰색 계열을 기준으로 맞춘다.
- CLASS 010은 검정 머리, 노랑 장식, 피부색, 초록 의상, 주황 하의/신발, 갈색 지팡이, 회색/하늘 그림자 계열을 기준으로 맞춘다.
- 팔레트는 전역 변경이 아니라 class id별 override로 적용한다.

## 4. 구현 방향

- `extract_fq4_class_icons.py`에 class id별 팔레트 override 구조를 추가한다.
- 기본 팔레트는 유지하고, 000과 010만 우선 override한다.
- 확인용 이미지를 `docs/fq4/analysis/031/`에 생성한다.
- 사용자가 확인한 뒤 같은 구조로 다른 CLASS도 쉽게 추가할 수 있게 한다.

## 5. 검증

- CLASS 000, 010 확인용 이미지가 샘플 색상에 가까운지 확인한다.
- CLASS 25, 174, 211, 217, 218 등 레이아웃 보정 항목이 깨지지 않는지 확인한다.
- `class_catalog.json` 220개 항목을 유지한다.
- 필요하면 세이브 에디터 EXE를 다시 빌드한다.

## 6. 원본 보존

`original/`, `patched/`, `korean-patch/`, `memcard/`, `savestates/`, `dos-save/`는 읽기만 하며 수정하지 않는다.

## 7. 완료 조건

- CLASS 000과 010의 팔레트 override가 적용된다.
- 확인용 이미지와 완료 문서가 작성된다.
- 최종 반영 시 EXE가 갱신된다.
