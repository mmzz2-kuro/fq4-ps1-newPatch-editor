# FQ4-PLAN-021 현재 파일 저장 및 CLASS 이미지 미리보기

- 작성일: 2026-09-14
- 상태: **완료**
- 선행 작업: PLAN-019 프리셋 정보 표시, PLAN-020 RetroArch 메모리카드 지원
- 사용자용 도구: `tools/FQ4SaveEditor/`
- 최종 실행 파일: `tools/dist/FQ4-PS1-Save-Editor.exe`
- 완료 문서 예정: `docs/fq4/finish/021-save-in-place-and-current-class-preview.md`

## 1. 목적

현재 불러온 메모리카드에 편집 결과를 바로 저장하는 기능을 추가하고, 선택한 캐릭터의 CLASS 이미지를 캐릭터 편집 화면에서 즉시 확인할 수 있게 한다.

## 2. 현재 파일 저장

- 상단에 `현재 파일 저장` 버튼을 추가한다.
- 버튼을 누르면 `정말로 덮어 씌우시겠습니까?` 확인 메시지를 표시한다.
- 사용자가 확인한 경우에만 현재 불러온 `.mcd` 또는 `.srm` 경로에 저장한다.
- 취소하면 파일을 전혀 변경하지 않는다.
- 저장 전 현재 파일 경로와 로드 상태를 확인하고, 저장할 파일이 없으면 안내한다.
- 기존 `다른 이름으로 저장` 기능은 그대로 유지한다.
- 저장 엔진의 임시 파일 작성·검증·원자적 교체 절차를 그대로 사용해 저장 도중 원본이 불완전한 파일이 되는 위험을 줄인다.
- 저장 후 파일을 다시 열어 PS1 디렉터리와 FQ4 내부 체크섬 및 바이트 결과를 검증한다.

`현재 파일 저장`은 사용자가 명시적으로 확인한 경우에만 불러온 파일을 덮어쓴다. 프로젝트의 ROM 및 패치 원본은 이 기능의 대상이 아니다.

## 3. 현재 CLASS 이미지 표시

- 오른쪽 `캐릭터 편집` 패널의 CLASS 항목 가까이에 32×32 대표 이미지를 표시한다.
- 캐릭터 목록에서 캐릭터를 선택하면 해당 캐릭터의 현재 CLASS ID에 맞는 이미지가 즉시 표시된다.
- CLASS 콤보박스에서 다른 클래스를 선택하면 저장 전이라도 미리보기 이미지가 즉시 바뀐다.
- `이미지 목록에서 CLASS 선택`으로 고른 경우에도 같은 미리보기를 즉시 갱신한다.
- 기존에 승인된 150개 CLASS 이미지와 팔레트를 그대로 사용한다.
- CLASS 정보는 기존처럼 ID·이름으로 표시하고 이미지를 함께 제공한다.
- 이미지 참조를 유지해 Tkinter에서 미리보기가 사라지지 않게 한다.

## 4. 검증

- 현재 파일 저장에서 취소 시 입력 파일 SHA-256이 바뀌지 않는지 확인한다.
- 확인 후 저장 시 변경한 캐릭터 값과 모든 체크섬이 정상인지 제어된 작업 파일로 검증한다.
- `.mcd`와 `.srm` 모두 입력 확장자와 현재 경로를 유지하는지 확인한다.
- 캐릭터 선택, CLASS 콤보 선택, 이미지 목록 선택 시 미리보기 갱신 경로를 확인한다.
- Python 구문 검사와 기존 `.mcd`·`.srm` 회귀 테스트를 실행한다.
- EXE를 재빌드하고 GUI 기동 상태를 확인한다.

## 5. 원본 및 작업 파일 관리

- ROM 관련 `original/`, `patched/`, `korean-patch/`는 수정하지 않는다.
- 자동 검증은 `work/fq4/save-editor/`의 기존 제어 파일을 재사용한다.
- `memcard/`, `savestates/`, `dos-save/`의 입력 파일은 자동 테스트에서 수정하지 않는다.
- 실제 사용 중 `현재 파일 저장`을 선택한 파일만 사용자 확인 후 덮어쓴다.

## 6. 완료 조건

- 확인 대화상자를 거쳐 현재 `.mcd` 또는 `.srm` 파일에 저장할 수 있다.
- 기존 `다른 이름으로 저장`이 정상 동작한다.
- 선택한 캐릭터와 현재 CLASS 선택에 맞는 이미지가 편집 화면에 즉시 표시된다.
- 기존 편집·프리셋·체크섬 기능에 회귀가 없다.
- 새 EXE와 완료 문서가 생성된다.
