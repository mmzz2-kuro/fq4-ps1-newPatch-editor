# FQ4-PLAN-019 세이브 에디터 프리셋 정보 표시

- 작성일: 2026-09-14
- 상태: **완료**
- 선행 작업: PLAN-018 세이브 에디터 프리셋 및 CLASS 이미지 UI
- 사용자용 도구: `tools/FQ4SaveEditor/`
- 최종 실행 파일: `tools/dist/FQ4-PS1-Save-Editor.exe`
- 완료 문서 예정: `docs/fq4/finish/019-save-editor-preset-details.md`

## 1. 목적

프리셋을 실제 캐릭터에 적용하기 전에 어떤 항목과 값이 저장되어 있는지 확인할 수 있도록, 캐릭터 편집 하단의 프리셋 영역에 읽기 전용 정보 표시부를 추가한다.

## 2. UI 변경

- 프리셋 선택 상자와 관리 버튼 아래에 읽기 전용 정보 표시부를 배치한다.
- 프리셋을 선택하면 기본 항목 `HR`, `HP`, `AT`, `AR`, `DF`, `DR`의 값을 표시한다.
- 해당 프리셋에 선택적으로 포함된 `CLASS`, `LV`, `FT`도 표시한다.
- `CLASS`는 숫자 ID와 클래스 이름을 함께 표시한다.
- 포함되지 않은 선택 항목은 `미포함`으로 표시해, 적용 시 기존 캐릭터 값이 유지된다는 점을 알 수 있게 한다.
- 프리셋이 없거나 선택되지 않았으면 안내 문구를 표시한다.
- 프리셋 선택 변경, 저장, 삭제 직후 표시 내용이 자동으로 갱신되게 한다.

## 3. 구현 범위

- `tools/FQ4SaveEditor/app.py`의 프리셋 UI와 표시 갱신 로직 수정
- 기존 프리셋 JSON 형식과 저장 위치 유지
- 능력치 제한, 다중 적용, CLASS 이미지 선택 및 메모리카드 저장 동작 유지
- 사용자 입력이 불가능한 읽기 전용 위젯으로 구현

## 4. 검증

- 일반 프리셋의 여섯 기본 능력치가 정확히 표시되는지 확인한다.
- `CLASS`, `LV`, `FT`의 포함·미포함 상태가 정확히 표시되는지 확인한다.
- 프리셋 선택 변경, 새 프리셋 저장, 삭제 후 즉시 갱신되는지 확인한다.
- Python 구문 검사와 기존 메모리카드 회귀 테스트를 실행한다.
- EXE를 재빌드하고 GUI가 정상적으로 기동하는지 확인한다.

## 5. 원본 보존

`original/`, `patched/`, `korean-patch/`, `memcard/`, `savestates/`, `dos-save/`는 읽기만 하며 수정하지 않는다. 새 ROM 복사본도 만들지 않는다.

## 6. 완료 조건

- 선택한 프리셋의 전체 적용 정보를 하단에서 읽기 전용으로 확인할 수 있다.
- 기존 편집·프리셋·저장 기능이 회귀 없이 동작한다.
- 새 EXE와 완료 문서가 생성된다.
