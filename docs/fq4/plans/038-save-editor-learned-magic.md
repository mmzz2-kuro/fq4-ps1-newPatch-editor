# FQ4 PLAN-038: 세이브 에디터의 배운 마법 편집

작성일: 2026-09-20
상태: 실행 완료 (결과: `docs/fq4/finish/038-save-editor-learned-magic.md`)

## 목표

PS1 세이브 에디터에서 마법 사용이 가능한 캐릭터의 배운 마법을 확인하고 변경할 수 있게 한다. 게임에서 실제로 사용할 수 있는 마법만 표시하며, 저장 후 다시 불러와도 선택 상태가 유지되도록 한다.

## 현재 확인된 사실

- 세이브의 캐릭터 배열은 payload `0x09A6`부터 32바이트씩 640개다.
- 현재 파서는 이름 ID, 클래스, 레벨, HP와 능력치만 해석한다. 배운 마법의 저장 위치나 형식은 아직 확인되지 않았다.
- 클래스 이름과 ID 자료는 에디터에 있지만, 어느 클래스가 마법을 사용할 수 있는지는 검증된 목록이 없다.
- 따라서 마법 편집 UI보다 세이브 구조와 게임의 판정 규칙을 먼저 확인해야 한다.

## 작업 순서

1. 기존 메모리카드와 세이브 스테이트를 읽기 전용으로 비교한다. 마법 사용자와 비사용자의 캐릭터 레코드에서 아직 해석하지 않은 바이트를 조사하고, 마법 습득 전후 자료가 있으면 차이를 대조한다.
2. 원본 및 한글패치 ROM에서 마법 목록, 마법 ID, 습득 상태의 읽기·쓰기 루틴을 찾는다. 세이브 값이 비트 목록인지, 슬롯 배열인지, 클래스별 고정 마법인지 확인한다.
3. 마법 사용 가능 조건을 확인한다. 클래스 ID만으로 판단하는지, 캐릭터별 플래그나 별도 능력치가 필요한지 조사한다. 불확실한 클래스는 임의로 편집 가능 처리하지 않는다.
4. 한글패치 ROM의 마법 이름을 ID와 연결한다. 이름을 확인할 수 없는 ID는 숫자로 표시하고 근거 수준을 기록한다.
5. 확인된 구조에 한해 `tools/scripts/fq4_memcard.py`에 읽기·쓰기와 범위 검사를 추가한다. 다른 캐릭터 필드와 미해석 바이트는 그대로 보존하고 체크섬을 갱신한다.
6. `tools/FQ4SaveEditor/`의 캐릭터 편집 영역에 배운 마법 표시 및 선택 기능을 추가한다. 마법을 사용할 수 없는 캐릭터는 편집을 비활성화하고 이유를 표시한다. 기존 저장·다른 이름으로 저장 흐름을 사용한다.
7. 원본을 복사한 테스트 세이브에서 변경 바이트 범위, 재읽기 결과, 체크섬을 검증한다. 가능하면 DuckStation에서 습득 마법 표시와 실제 사용 가능 여부도 확인한다. 검증되지 않은 효과는 완료로 주장하지 않는다.
8. `docs/fq4/analysis/038/`에 구조·근거·미확인 사항을 기록하고, 작업 완료 후 `docs/fq4/finish/038-save-editor-learned-magic.md`를 작성한다. GUI 실행 파일도 기존 빌드 방식으로 갱신한다.

## 보존 및 파일 배치

- `original/`, `patched/`, `korean-patch/`, `memcard/`, `savestates/`, `dos-save/`의 입력 파일은 수정하지 않는다.
- 분석 스크립트와 세이브 구조 구현은 `tools/scripts/`에 둔다. GUI 코드는 `tools/FQ4SaveEditor/`에 둔다.
- 테스트 세이브와 중간 결과는 `work/fq4/038/`에 두고 같은 사본을 재사용한다. ROM 전체 사본은 필요성이 확인되기 전에는 만들지 않는다.

## 검증 기준과 중단 조건

- 최소 두 캐릭터 또는 전후 세이브와 ROM 코드 근거로 저장 형식을 교차 확인한다.
- 한 캐릭터의 마법 변경이 다른 캐릭터, 능력치, 아이템, 자금을 바꾸지 않아야 한다.
- 저장 후 재열기와 체크섬 검증이 통과해야 한다.
- 저장 위치나 마법 ID의 의미가 확인되지 않으면 추측에 기반한 쓰기 기능은 넣지 않고, 분석 결과와 추가로 필요한 자료를 문서화한다.
