# FQ4-PLAN-003 — 일반 BIOS 대표 화면 시각 런타임 검증 계획

- 작성일: 2026-09-13
- 상태: **작업 완료 — 사용자 캡처로 일반 BIOS 메뉴 글리프 실패 확인**
- 선행 결과: [FQ4-FINISH-002](../finish/002-bios-independent-font-poc.md)
- 기준 ROM: `work/fq4/rom/current.bin`의 BIOS 독립 최소 글리프 PoC
- 기준 BIOS: `original/scph1001.bin`
- 완료 문서 예정: `docs/fq4/finish/003-normal-bios-visual.md`

## 1. 목적

일반 PS1 BIOS로 현재 PoC ROM을 새로 부팅하고 정상적인 게임 진행을 통해 대표 문자열이 나오는 화면에 진입한다. 최초 대표 문자열은 “교섭중”이었으나, 2026-09-13 사용자 관찰에 따라 쉽게 재현 가능한 지도 메뉴의 `시간경과`, `부대이동`, `탐색`으로 변경했다. 일반 BIOS와 동봉 한글 BIOS 화면을 비교해 최종 화면 표시 차이를 직접 관찰한다.

선행 작업은 일반 BIOS에서 실제 게임 훅, 변환 함수와 `LoadImage` 호출까지 연결된다는 사실을 입증했다. 이번 작업은 아직 남은 경계인 **GPU 업로드 이후 최종 화면 가시성 및 정상 플레이 도달성**만 검증한다.

## 2. 승인 범위

- 일반 BIOS와 현재 PoC ROM의 식별값을 다시 확인한다.
- 같은 portable DuckStation 환경에서 ROM을 새 부팅한다.
- 정상 게임 입력 또는 새 부팅 이후 생성한 세이브 상태를 이용해 대표 화면에 진입한다.
- “교섭중” 세 글자의 형태와 배치, 주변 UI를 캡처하고 관찰 기록을 남긴다.
- 대표 화면을 종료한 뒤 다시 진입하여 글리프와 UI가 유지되는지 확인한다.
- 로그, 캡처, 판정 근거를 `work/fq4/003/`과 `docs/fq4/analysis/003/`에 정리한다.
- 결과를 `docs/fq4/finish/003-normal-bios-visual.md`에 통과·실패·미해결 중 하나로 기록한다.

전체 글리프 이관, 전체 텍스트 조사, PoC 코드 확장, 제품용 저장·RAM 설계, 배포 패치 제작과 실기 검증은 이번 범위에 포함하지 않는다.

## 3. 보존 및 용량 규칙

- `original/`, `patched/`, `korean-patch/`는 읽기 전용으로 취급하며 수정·이동·삭제하지 않는다.
- 일반 BIOS는 이미 생성한 `work/fq4/tools/duckstation/bios/scph1001.bin` 한 벌을 계속 재사용한다.
- 전체 작업용 ROM은 `work/fq4/rom/current.bin` 한 벌만 사용한다. 새 BIN·ISO·IMG 복사본을 만들지 않는다.
- 세이브 상태가 필요하면 현재 PoC ROM으로 새로 생성하며, 테스트 목적과 생성 조건을 기록한다. 이전 ROM에서 만든 상태를 재사용하지 않는다.
- 분석·자동화 스크립트는 `tools/scripts/`에 작성한다. 사용자용 GUI 도구는 만들지 않는다.
- 캡처와 로그는 ROM 전체 복사본이 아닌 최소 근거만 보존한다.

## 4. 입력 고정

작업 시작 시 다음 항목을 기록하고 선행 결과와 일치하지 않으면 실행을 중단한다.

| 입력 | 기대값 |
|---|---|
| 일반 BIOS SHA-256 | `71af94d1e47a68c11e8fdb9f8368040601514a42a5a399cda48c7d3bff1e99d3` |
| PoC ROM SHA-256 | `e419b4018a8aa02facc3a425ef05f325cb0fc0130e5822015ce43fa2e0baded9` |
| PoC ROM 크기 | 101,140,704바이트 |
| CUE | `work/fq4/rom/current.cue` |
| 게임 ID | `SLPS-00604` |
| BIOS 버전 | `System ROM Version 2.2 12/04/95 A` |

최초 ROM 조사 당시의 입력 목록은 수정하지 않는다. 추가된 일반 BIOS는 선행 작업의 `bios-comparison.json`을 기준으로 재검증한다.

## 5. 실행 절차

### A. 환경 초기화와 부팅 확인

1. DuckStation 프로세스가 남아 있지 않은지 확인한다.
2. portable 설정이 일반 BIOS를 선택하는지 확인한다.
3. 기존 런타임 개입 검사의 임시 상태를 사용하지 않고 `current.cue`를 새 부팅한다.
4. 로그에서 선택 BIOS, 게임 ID, 시스템 부팅과 커널 초기화를 기록한다.
5. 일본판 디스크와 NTSC-U BIOS의 지역 불일치 경고가 있더라도 부팅이 정상 완료되면 계속하되 환경 차이로 기록한다.

### B. 대표 화면 정상 진입

1. 새 게임 또는 정상적인 게임 입력으로 “교섭중” 문자열이 사용되는 화면까지 진행한다.
2. 정확한 진입 절차를 알 수 없으면 먼저 기존 250826 텍스트·코드 참조와 런타임 추적으로 해당 화면의 호출 조건을 좁힌다.
3. 정상 입력 절차를 찾은 경우 입력 순서와 시작 상태를 재현 가능하게 기록한다.
4. 상태 개입이 불가피하면 정상 플레이 증거와 분리해 기록하며, 그것만으로 정상 도달성을 통과 처리하지 않는다.

### C. 화면 관찰

대표 화면에서 다음을 확인한다.

- `8952`, `8EB5`, `917E`가 각각 “교”, “섭”, “중” 형태로 보이는지.
- 글자가 깨지거나 잘리거나 뒤집히지 않는지.
- 글자 간격, 기준선, 색상과 배경 처리가 주변 문자와 일관적인지.
- 메뉴, 초상화, 창 테두리와 주변 UI에 손상이 없는지.
- 같은 화면에서 일반 BIOS 폴백 문자가 함께 쓰일 경우 정상인지.

전체 화면 캡처 한 장과 글리프를 판별할 수 있는 확대 근거를 남긴다. 캡처가 불가능하면 관찰자, 시점, 화면 내용과 제한을 텍스트로 기록하되 시각 통과 판정은 보류한다.

### D. 종료·재진입과 상태 수명

1. 대표 화면을 정상적으로 종료한다.
2. 다른 화면을 거친 뒤 같은 화면에 다시 진입한다.
3. 두 번째 진입에서도 세 글리프와 주변 UI가 같은지 확인한다.
4. 가능하면 화면 전환 전후에 훅 및 `LoadImage` 호출 횟수를 기록하여 재업로드 여부를 구분한다.
5. 종료 후 다른 화면에서 글리프 잔상, VRAM 오염 또는 UI 손상이 없는지 확인한다.

### E. 정리와 보존 확인

1. DuckStation을 종료한다.
2. 원본 게임, 일반 BIOS, 동봉 BIOS, xdelta와 작업용 ROM의 해시를 다시 확인한다.
3. `work/fq4/rom/`에 BIN이 `current.bin` 한 벌뿐인지 확인한다.
4. 불필요한 임시 캡처와 로그를 제거하고 판정에 필요한 최소 근거만 남긴다.

## 6. 판정 기준

### 통과

다음 조건을 모두 만족해야 한다.

1. 일반 BIOS로 새 부팅한 현재 PoC ROM에서 정상 게임 입력을 통해 대표 화면에 도달한다.
2. “교섭중” 세 글자가 판독 가능한 올바른 형태로 표시된다.
3. 주변 UI, 일반 문자와 화면 전환에 관찰 가능한 손상이 없다.
4. 화면 종료 후 재진입해도 같은 결과가 재현된다.
5. 원본 입력과 작업용 ROM 해시가 작업 전후 동일하다.

### 실패

다음 중 하나가 재현되면 실패로 기록한다.

- 한글 글리프가 비어 있거나 다른 문자, 깨진 모양 또는 잘린 모양으로 표시된다.
- 색상, 간격, 기준선 또는 배경 처리 오류로 문자열을 정상적으로 읽을 수 없다.
- 주변 UI나 다른 문자가 손상된다.
- 화면 종료·재진입 뒤 글리프가 사라지거나 VRAM 오염이 생긴다.
- 일반 BIOS에서 부팅 또는 정상 진행이 PoC 변경 때문에 실패한다.

실패 시 최초 이상 지점을 조회, 변환, 업로드, VRAM 유지, 그리기 중 하나로 좁혀 완료 문서에 다음 실험 후보를 기록한다. 이번 승인으로 구현을 수정하거나 새 ROM을 만들지는 않는다.

### 미해결

다음 경우에는 성공으로 추정하지 않고 미해결로 기록한다.

- 대표 화면까지의 정상 입력 절차를 찾지 못한다.
- 에뮬레이터 화면을 관찰하거나 캡처할 수 없다.
- 상태 개입으로만 화면에 도달하여 정상 플레이 도달성을 판단할 수 없다.
- 지역 불일치 등 환경 차이가 결과 판정을 방해한다.
