# FQ4 PLAN-016 분석 및 검증 결과

종족 제한 확장은 기존 BIOS 독립 패치 엔진에서 분리된 `build_party_race_limit_patch.py` 모듈로 유지했다. 이 모듈은 raw BIN의 메모리 이미지에 적용하는 함수와 파일 단위 CLI를 함께 제공한다. 적용 전에 8개 MIPS 명령이 모두 원본 예산값 `0x1E0`인지 확인하며, 이미 적용됐거나 예상하지 않은 입력은 거부한다.

기존 GUI에는 기본값이 꺼진 **부대 종족 제한을 18종 수준으로 확장 (실험적)** 체크박스를 추가했다. 체크 상태는 `--expand-party-species-limit` 인자로 공통 빌드 엔진에 전달된다. 체크 해제 경로는 기존 결과 SHA-256 `616ae2...`와 같고, 체크 선택 경로는 사용자가 기본 동작을 확인한 PLAN-015 결과 `684d47...`와 같다.

Python 엔진과 frozen EXE에서 두 경로를 각각 실행했다. 모든 실행은 기대 해시와 일치했다. 체크 해제와 선택 결과를 전체 43,002개 sector 검사했으며 sync, header, subheader, EDC, P와 Q 오류는 모두 0이었다. 체크 선택 결과의 8개 비교 명령도 7개 `28420361`, 1개 `29820361`로 확인했다.

이 검증은 빌드 재현성, 기계어 변경과 디스크 무결성을 확정한다. 서로 다른 종족으로 구성한 부대를 장시간 운용하며 이동, 전투, 합류·분리와 세이브·로드를 반복하는 플레이 검증은 계속 남아 있다. GUI에서 이 기능을 실험적으로 표시하는 이유다.
