# First Queen IV PS1 ROM table/location notes

작성일: 2026-09-15

이 문서는 현재까지 `FQ4` PS1 한글패치 분석에서 확인한 주요 데이터 위치를 빠르게 참조하기 위한 요약입니다. 원본 ROM, 패치 ROM, 패치 파일 자체는 수정하지 않고, 기존 분석 결과와 빌더/에디터 구현에서 확정된 위치를 정리했습니다.

## 전체 구조 요약

| 구분 | 위치 | 확정도 | 비고 |
|---|---|---|---|
| 실행 파일 / 주요 텍스트 / 테이블 | `/SLPS_006.04;1` | 높음 | 메뉴 문자열, 이름, 아이템명, 정산 화면 라벨, 관련 코드 포함 |
| 지도 메뉴 문자열 | `/SLPS_006.04;1` 내부 | 높음 | `시간경과`, `부대이동`, `탐색` 확인 |
| 캐릭터명 테이블 | `/SLPS_006.04;1` `0xE86B0` | 높음 | 640개, 엔트리 폭 10 bytes |
| 아이템명 테이블 | `/SLPS_006.04;1` `0xE67D5` | 높음 | 72개, 엔트리 폭 17 bytes, 세이브 item_id는 1-based |
| 클래스명 테이블 | `/SLPS_006.04;1` 내부 | 중간~높음 | 세이브 에디터용 데이터화 완료. 정확한 원본 테이블 문서화는 추가 정리 필요 |
| 엔딩 정산 화면 라벨 | `/SLPS_006.04;1` `0xE0400` | 높음 | 템플릿 길이 `0xB0` |
| 엔딩 동영상 | `/MOV/MOV03.STR;1`, `/MOV/MOV04.STR;1` | 높음 | 한글 자막은 STR 영상 데이터 쪽에 포함 |
| 타이틀 그래픽 | `/SYS/TITLE1.GRP;1`, `/SYS/TITLE2.GRP;1` | 높음 | 한글패치에서 변경된 그래픽 파일 |

## 한글패치에서 변경된 파일

초기 ROM 비교 기준으로 한글패치가 변경한 파일은 다음 5개입니다.

| 파일 | 용도 추정 / 확인 내용 |
|---|---|
| `/SLPS_006.04;1` | 실행 파일. 텍스트, 테이블, 렌더링 코드, 패치 코드 포함 |
| `/MOV/MOV03.STR;1` | 동영상 STR. 한글 자막 영상 데이터 포함 |
| `/MOV/MOV04.STR;1` | 엔딩 동영상 STR. 한글 자막 영상 데이터 포함 |
| `/SYS/TITLE1.GRP;1` | 타이틀 그래픽 |
| `/SYS/TITLE2.GRP;1` | 타이틀 그래픽 |

## 대사 / 문자열 위치

일반 대사 전체 추출은 아직 완료된 상태가 아닙니다. 다만 현재까지 확인한 메뉴/고정 문자열은 `/SLPS_006.04;1` 내부에 있습니다.

| 문자열 | 파일 | 오프셋 | 비고 |
|---|---|---:|---|
| `시간경과` | `/SLPS_006.04;1` | `0x12D0` | 지도 메뉴 문자열 |
| `부대이동` | `/SLPS_006.04;1` | `0x12DE` | 지도 메뉴 문자열 |
| `탐색` | `/SLPS_006.04;1` | `0x12EC` | 지도 메뉴 문자열 |
| `탐색` | `/SLPS_006.04;1` | `0xD5D1B` | 다른 문맥에서 재사용 |

한글패치의 일반 텍스트는 Shift-JIS 영역처럼 보이는 2바이트 game-code를 사용하고, 실제 한글 표시는 패치된 BIOS 글리프 또는 내장 글꼴 로더가 처리합니다. 현재 변환/표시는 `docs/fq4/analysis/005/encoding-map.json`의 game-code 매핑을 기준으로 분석했습니다.

## 캐릭터명 테이블

세이브 데이터에는 이름 문자열이 직접 저장되지 않고 `name_id`가 저장됩니다. 세이브 에디터는 세이브의 `name_id`를 읽고, 실행 파일에서 추출한 캐릭터명 목록과 매칭해서 보여줍니다.

| 항목 | 값 |
|---|---:|
| 파일 | `/SLPS_006.04;1` |
| 테이블 시작 오프셋 | `0xE86B0` |
| 엔트리 수 | `640` |
| 엔트리 폭 | `10 bytes` |
| 관련 생성 스크립트 | `tools/scripts/generate_fq4_editor_names.py` |
| 에디터 데이터 | `tools/FQ4SaveEditor/character_names.json` |

## 아이템명 테이블

세이브의 아이템 ID는 1-based로 해석합니다. 즉 `item_id 1`이 아이템명 테이블의 첫 번째 항목입니다.

| 항목 | 값 |
|---|---:|
| 파일 | `/SLPS_006.04;1` |
| 테이블 시작 오프셋 | `0xE67D5` |
| 엔트리 수 | `72` |
| 엔트리 폭 | `17 bytes` |
| 관련 분석 스크립트 | `tools/scripts/analyze_fq4_item_names.py` |
| 에디터 데이터 | `tools/FQ4SaveEditor/item_names.json` |
| 분석 문서 | `docs/fq4/analysis/035/README.md` |

엔딩 후 내 캐릭터 정산/결과 화면의 고정 라벨은 `/SLPS_006.04;1` 내부 템플릿에서 확인했습니다.

| 항목 | 값 |
|---|---:|
| 파일 | `/SLPS_006.04;1` |
| 템플릿 시작 오프셋 | `0xE0400` |
| 템플릿 길이 | `0xB0` |
| 관련 완료 문서 | `docs/fq4/finish/034-ending-post-movie-black-screen.md` |
| 한글 자막 유지 수정 문서 | `docs/fq4/finish/037-ending-korean-movie-preserve.md` |

현재 반영된 라벨 치환은 다음과 같습니다.

| 원문 | 한글 |

## 엔딩 동영상 / MOV04 관련

`MOV04` 전체를 원본으로 되돌리면 정산 화면 전환은 살아나지만, 한글 자막 엔딩 동영상이 일본어 원본으로 돌아갑니다. 최종 적용 방식은 한글 MOV04 본문을 유지하고 마지막 64 raw sectors만 원본 종료부로 사용하는 방식입니다.

| 항목 | 값 |
|---|---:|
| 파일 | `/MOV/MOV04.STR;1` |
| MOV04 LBA 범위 | `18430..22652` |
| 한글 MOV04 유지 범위 | `18430..22588` |
| 원본 종료부 사용 범위 | `22589..22652` |
| 원본 종료부 사용량 | `64 raw sectors` |
| 관련 분석 문서 | `docs/fq4/analysis/037/README.md` |
| 관련 완료 문서 | `docs/fq4/finish/037-ending-korean-movie-preserve.md` |

## 세이브 데이터와 ROM 테이블의 관계

세이브 에디터 기준으로 확인한 주요 세이브 구조는 다음과 같습니다.

| 구분 | 세이브 내부 오프셋 / 구조 | ROM 테이블 참조 |
|---|---|---|
| 캐릭터 레코드 | `0x09A6`, stride `0x20`, count `640` | `name_id` → 캐릭터명 테이블, `class_id` → 클래스명/스프라이트 데이터 |
| 아이템 | `0x0492`, stride `2`, capacity `71` | `item_id` → 아이템명 테이블, 1-based |
| 자금 | `0x0692` | 게임 내 표시 자금은 입력값 × 10 |

관련 구현 파일은 `tools/scripts/fq4_memcard.py`와 `tools/FQ4SaveEditor/app.py`입니다.

## 남은 정리 필요 항목

- 일반 대사 전체 테이블 위치와 포인터 구조는 아직 별도 완료 문서로 확정하지 않았습니다.
- 클래스명 원본 테이블 위치는 세이브 에디터 데이터로는 사용 중이지만, `캐릭터명/아이템명`처럼 별도 표로 정리하려면 추가 분석이 필요합니다.
- STR 동영상 자막은 텍스트 테이블이 아니라 영상 데이터에 박힌 형태로 보는 것이 현재까지의 실무 기준입니다.
